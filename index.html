Zabezpečenie Firestore Rules

Vložte tieto bezpečnostné pravidlá do konzoly Firebase Firestore (záložka Rules) pre overovanie rolí. Smenári majú povolené len čítať, kým administrátori s overeným emailom (alebo s rovnakými administrátorskými právami) majú práva na plný zápis:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Rozpisy a jednotliví zamestnanci match /rosters/{rosterId} { allow read: if true; // Zamestnanci čítajú bez registrácie allow write: if request.auth != null && request.auth.token.email.matches('(?i).*admin.*|.*antipro18@gmail.com'); match /employees/{employeeId} { allow read: if true; allow write: if request.auth != null && request.auth.token.email.matches('(?i).*admin.*|.*antipro18@gmail.com'); } } // Žiadosti o push notifikácie match /fcm_requests/{requestId} { allow read: if false; // Zamestnanci nečítajú logy správ allow write: if request.auth != null && request.auth.token.email.matches('(?i).*admin.*|.*antipro18@gmail.com'); } } }
